## In-app updates

- Check for new stable releases at startup (including login when **Open at login**
  is enabled), then every 24 hours while KMSA stays open.
- A discreet dot on the menu-bar speaker indicates an available update.
- Use **Update to x.x.x / Mettre à jour vers x.x.x** to download and install from
  the app. The button becomes a real download-progress bar, followed by verification
  and restart. Once complete, it shows **KMSA is up to date / KMSA est à jour**.
- Downloads are checked against the official GitHub release digests and manifest,
  then checked for compatibility and app integrity. Settings are preserved, with a
  recovery copy of the previous app. Installation always requires a click.
