Add in-app updates in English and French: choose **Check for Updates… / Rechercher
une mise à jour…**, then **Install and Relaunch / Installer et relancer** to
download and install a newer stable GitHub release without moving the app by hand.
The updater checks SHA-256 digests, macOS compatibility and app integrity before
replacement, preserves settings, and retains the previous app for recovery.
